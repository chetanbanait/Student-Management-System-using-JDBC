🎯 Main Objective of the Project

The primary objective of the Student Management System is to design and develop a Java-based application using JDBC and PostgreSQL that efficiently manages student, course, and enrollment data while demonstrating real-world database interaction and clean software architecture.

📌 Detailed Objectives
To understand and implement JDBC database connectivity in Java
To perform CRUD operations (Create, Read, Update, Delete) on multiple entities
To implement batch processing for efficient bulk data insertion
To integrate and execute PostgreSQL stored procedures and functions
To apply a layered architecture (Entity → DAO → Service → Main) for better code structure
To design a normalized relational database schema
To manage and version control the project using Git & GitHub
